CSV Folio · Android

隱私權政策

最後更新：2026年10月5日

Motoki Takahashi（以下稱「營運者」）就 Android 應用程式「CSV Folio」（以下稱「本應用程式」）的使用者資訊處理方式說明如下。

CSV 的瀏覽與編輯原則上在裝置內進行。營運者沒有自行營運用於儲存使用者資料的伺服器。但資訊可能傳送至用於故障分析等目的的外部服務並由其保存，因此並不代表完全不蒐集或儲存任何資訊。

1. CSV 檔案與裝置內資訊

本應用程式讀取您選擇的 CSV 檔案或輸入的文字，並將其內容、匯入資料、索引與顯示設定等儲存在裝置內的應用程式專用空間，以供瀏覽、編輯及搜尋。本應用程式沒有將這些 CSV 資料上傳至營運者伺服器的功能。

本應用程式不會將 CSV 內容作為廣告或使用情況分析事件、自訂記錄傳送。CSV 檔案如含有個人資料，也會作為檔案內容的一部分進行處理。

本應用程式無須註冊帳號，也不要求登記姓名、地址或電話號碼。

2. 外部服務與使用目的

本應用程式使用或計畫使用下列 Google 服務。實際傳送的資訊取決於版本、服務與裝置設定，以及同意選項。營運者可能透過服務控制台查看診斷和使用情況報表，並在加入廣告功能後查看廣告報表。

Firebase Crashlytics：故障分析

用於調查當機、無回應問題並改善穩定性。故障時間、堆疊追蹤、例外類型與訊息、應用程式版本、裝置型號、作業系統、記憶體，以及區分安裝或工作階段的識別碼等會傳送給 Google。例外訊息可能包含正在處理的檔案路徑。

詳情請參閱 Firebase 隱私權與安全性。

Google Analytics for Firebase：使用情況分析

用於了解使用情況及改善功能。公開版本會將首次啟動、工作階段、畫面瀏覽、使用時間、應用程式更新等自動蒐集事件，以及裝置、作業系統、應用程式資訊、語言、大概位置與應用程式執行個體 ID 等識別碼傳送給 Google。

本應用程式不會將 CSV 內容、檔名、搜尋字詞或使用者輸入的 URL 作為自訂分析事件傳送。廣告 ID 蒐集與允許分析資料用於個人化廣告的設定均已停用。目前沒有可在應用程式內僅關閉分析資訊傳送的設定。詳情請參閱 Google Analytics 資料蒐集說明。

Google AdMob：廣告放送（計畫加入）

計畫用於顯示廣告、評估成效與防止詐欺。加入後，IP 位址、大概位置、廣告 ID 等識別碼、裝置資訊、廣告曝光與點擊、診斷資訊等可能會傳送給 Google 或與其共用。

截至本政策更新日期，Android 版尚無廣告放送功能。加入時，我們將依廣告設定及放送地區提供適當的說明、同意和選擇機制，並更新本政策。即使是非個人化廣告，也可能使用放送及防止詐欺所需的資訊。詳情請參閱 Google Mobile Ads SDK 資料說明。

另請參閱 Google 隱私權政策及 Google 如何使用來自採用其服務的網站或應用程式的資訊。

3. URL 下載、圖片顯示與分享

透過 URL 下載 CSV，或使用顯示 CSV 內圖片 URL 的功能時，裝置會直接連線至該 URL 的伺服器。對方會收到 IP 位址及要求的 URL。若 URL 含有個人資料或驗證文字，也會一併傳送至該伺服器。

匯出或分享會將檔案交給您選擇的儲存位置、應用程式或服務。選擇雲端儲存服務時，檔案可能保存在該服務的伺服器。請參閱相關服務及接收方的隱私權政策。

4. 聯絡諮詢

透過電子郵件聯絡時，營運者會收到您的電子郵件地址、姓名（如有提供）、訊息及附件。這些資訊用於回覆、調查問題及保留必要的支援紀錄。請避免傳送機密資訊或含有調查不需要的個人資料的 CSV。

5. 保存期間與刪除

  • 已匯入的 CSV 資料與索引可從檔案清單刪除，也可在 Android 設定中清除本應用程式的儲存資料。
  • 從清單刪除不會刪除原始 CSV、匯出檔案或接收方保存的副本。請視需要在各儲存位置刪除。
  • Google Analytics 的事件與使用者層級資料依其資料保留設定保存與刪除。彙總報表可能不適用相同期間。解除安裝不會立即刪除已傳送至 Google 的資訊。
  • 分享用的暫存檔案，在建立滿七天後的下一次應用程式啟動或分享操作時刪除。作業系統可能更早清除快取。
  • 依 Google 公開說明，Crashlytics 的故障資訊與相關識別碼保存 90 天後，開始從運作中的系統與備份刪除。
  • 諮詢資訊僅在處理及保留必要紀錄所需期間保存，不再需要時刪除。如有法定保存義務，依該要求保留。

清除本地資料或解除安裝不會立即刪除已傳送至 Google 或接收方的資訊。有關查閱、刪除等問題，請透過下方聯絡方式洽詢。我們將依可管理範圍及各服務支援的機制處理。

6. 資訊管理與境外處理

本地資料保存在 Android 提供的應用程式專用空間。我們透過將諮詢資訊與外部服務控制台的存取限制在必要範圍等措施，致力保護資訊。

傳送至 Firebase 等外部服務的資訊，可能在 Google 或其受託方的設施內保存或處理，包括日本境外的設施。與 Firebase 的通訊經過加密。使用者指定 URL 的通訊是否加密，取決於該 URL 使用 HTTPS 或 HTTP。

7. 付費功能

截至本政策更新日期，本應用程式沒有應用程式內購買功能，也不取得信用卡等付款資訊。若未來加入付費功能而改變資訊處理方式，我們將更新本政策。

8. 本政策的變更

我們會依功能、服務及資訊處理方式的變化更新本政策。重要變更將透過應用程式或其他方式通知。法律或服務提供者要求時，我們會在蒐集或使用資訊前說明並徵求同意。
